# Звонки между колонками

Отдельный пакет `modules/calls.yaml` добавляет входящий вызов, ответ и
одновременную передачу звука в обе стороны. Он не требует модуля радионяни;
оба пакета можно установить вместе. Звонок и радионяня не занимают одну колонку
одновременно. В обычной прошивке без этого пакета звонки отсутствуют.

```yaml
packages:
  voice_pe:
    url: https://github.com/mikhailhimei/home-assistant-voice-pe
    ref: feat/speaker-calls
    files:
      - home-assistant-voice.yaml
      - modules/calls.yaml
    refresh: always
```

Сохраните свои имя, Wi-Fi и параметры API. Этот пакет нужен на обеих колонках.
Ключ отправки звука и IPv4 HA передаются/определяются автоматически через
существующее подключение ESPHome API. Не вводите ключи в YAML. TCP-порт 8125
должен быть доступен от колонок до HA; при Docker bridge опубликуйте его.

Сервер звонков встроен в ветку `feat/speaker-calls` **HA Dialog UI**. Управление:
`ha_dialog_ui.call_start` (`source_device_id`, `target_device_id`),
`ha_dialog_ui.call_answer` (`device_id` вызываемой колонки),
`ha_dialog_ui.call_end` (`device_id` любой колонки пары).
[Полная инструкция HA Dialog UI](https://github.com/mikhailhimei/ha-dialog-ui/blob/feat/speaker-calls/docs/calls.md).

Верхняя кнопка принимает входящий вызов; при исходящем вызове или разговоре
завершает его у обеих колонок. Mute и потеря API также завершают вызов.
Сам факт установки пакета не запускает микрофонный поток: передача начинается
только после ответа. После перезапуска вызов не возобновляется автоматически.

Микрофонный источник звонка работает в passive-режиме: не управляет общим
микрофоном, который используют MWW и Assist. Распознавание не отключается.
Звук собеседника воспроизводится через media pipeline, ответ Assist — через
announcement pipeline. Обычное приглушение media во время ответа Assist
сохраняется. Запуск другого media может прервать звонок. Прежняя музыка
после звонка автоматически не возобновляется.

Подавление эха XMOS, одновременный разговор и распознавание команд во время
него требуют проверки на двух физических Voice PE. Сборка подтверждает
совместимость конфигурации и кода, но не аппаратное качество звука.

### Индикация и мелодия

При исходящем или входящем вызове по кольцу бежит синий индикатор.
После ответа и подключения звука кольцо становится зелёным. После завершения
возвращается обычная индикация. Яркость берётся из настройки LED Ring.

В настройках устройства ESPHome в Home Assistant доступен список **«Мелодия звонка»**:
«Стандартная» (прежний звук), «Сигнал таймера», «Сигнал пробуждения», «Без звука».
Выбор сохраняется после перезапуска и действует на входящие вызовы этой колонки.
