# ESP32-WROOM-32 + INMP441: первый эксперимент

Ветка **`experimental/esp32-wroom32`**. Это отдельная прошивка для классического
ESP32-WROOM-32 (плата ESP32 DevKit с CH340/USB Type-C), не для Voice PE.
Ветка `dev` и прошивка Voice PE не изменяются.

Первый этап: один INMP441 слушает звук, локальная модель ищет фразу **«Окей, Набу»**,
при обнаружении устройство пишет **`1`** в лог и продолжает слушать.
Распознавания команд, передачи звука на HA, динамика, часов, таймеров,
радионяни и звонков в этом конфиге нет. Прежний YAML часов сюда переносить не нужно.

## Подключение INMP441

Отключите питание перед подключением.

| INMP441 | ESP32-WROOM-32 |
| --- | --- |
| VDD / VCC | **3V3**, не 5 В |
| GND | GND |
| SCK / BCLK | GPIO26 |
| WS / LRCL | GPIO25 |
| SD / DOUT | GPIO33 |
| L/R | GND — левый канал |

Не оставляйте L/R неподключённым. Надпись `SD` на микрофоне — выход данных,
его нужно подключить к входу ESP32. CH340 — USB–UART, в обработке звука не участвует.

## Прошивка через Git-пакет ESPHome

В ESPHome Device Builder создайте/замените конфигурацию именно этой ESP32-платы:

```yaml
substitutions:
  name: esphome-web-619b9c
  friendly_name: ESP32 Microphone

packages:
  wroom_microphone:
    url: https://github.com/mikhailhimei/home-assistant-voice-pe
    ref: experimental/esp32-wroom32
    files:
      - esp32-wroom32.yaml
    refresh: always

wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_password
```

При необходимости задайте своё имя устройства. Первую установку выполните
по USB на WROOM-плату. В дальнейшем можно обновлять OTA через ESPHome.
Если в вашей текущей конфигурации используется шифрование API, сохраните свой
блок `api.encryption` локально; ключи в публичный репозиторий добавлять не надо.

`home-assistant-voice.yaml` в этой ветке также включает минимальный WROOM-пакет,
но явное имя `esp32-wroom32.yaml` помогает не спутать его с прошивкой Voice PE.

## Проверка

Откройте логи ESPHome, дождитесь запуска `micro_wake_word` и скажите «Окей, Набу».
Ожидаемая строка:

```text
[I][wake_word:...]: 1
```

Фраза определяется на самой ESP32; сервер распознавания речи не нужен.
Подключение к API HA для детекции не требуется. Параметры Wi-Fi задаются локально.

## Ограничения первого этапа

WROOM-32 обычно не имеет PSRAM. Для этого эксперимента оставлена только одна
модель, без VAD и голосового диалога. ESPHome может использовать внутреннюю RAM,
но успешная сборка не гарантирует, что памяти и скорости хватит на вашей плате.
При нехватке памяти появится ошибка выделения буферов/tensor arena; при недостатке
скорости — сообщения переполнения или потери аудио. Сначала проверяем эти логи,
а затем постепенно добавляем функции.

Это не готовая замена Voice PE и не обещание такого же качества распознавания.
На реальной WROOM-плате прошивку ещё нужно проверить.


## Если нужна «Алиса» вместо «Окей, Набу»

Добавьте в локальный блок substitutions:

```yaml
  wake_word_model: https://raw.githubusercontent.com/mikhailhimei/home-assistant-voice-pe/dev/models/alisa.json
```

Это замена модели с последующей перепрошивкой, не загрузка двух моделей сразу.
